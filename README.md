# Move That Mouse

Repository for Move That Mouse. The GitHub Pages link stays get-the-cheese.

A 3D mouse maze game for iPad and web.

Play: https://ericplante-gitrepo.github.io/get-the-cheese/

v0.6 is the current release.

v0.5 stays playable at https://ericplante-gitrepo.github.io/get-the-cheese/v05/. To restore v0.5, copy `v05/index.html` to `index.html` on main, or reset main to tag `v0.5`.

v0.4 stays playable at https://ericplante-gitrepo.github.io/get-the-cheese/v04/. To restore v0.4, copy `v04/index.html` to `index.html` on main, or reset main to tag `v0.4`.
