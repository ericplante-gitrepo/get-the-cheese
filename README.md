# get-the-cheese
Repository for get-the-cheese

A 3D mouse maze game for iPad and web.

Play: https://ericplante-gitrepo.github.io/get-the-cheese/

v0.5 adds the "Up High" levels 11-20 and the phone layout fix.

v0.4 stays playable at https://ericplante-gitrepo.github.io/get-the-cheese/v04/. To restore v0.4, copy `v04/index.html` to `index.html` on main, or reset main to tag `v0.4`.
